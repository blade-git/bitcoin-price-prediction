# 비트코인 가격 예측 : 데이스쿨 구독자 전용 AI 해커톤
* 주최/주관 : 데이콘
* 원문 링크 : 
## 1. 배경
이 해커톤은 비트코인 데이터를 활용해 미래의 비트코인 가격을 예측하는 알고리즘을 개발하는 것을 목표로 함. 비트코인은 디지털 금융 시장에서 가장 잘 알려진 암호화폐로, 그 가치는 시장의 수많은 변수에 의해 결정. 아래의 가상 환경을 설정하여 진행됨.
* **가상 환경** : 데이콘 거래소를 통해 수집된 비트코인 거래 정보와 관련된 데이터를 활용하여 비트코인 가격을 예측
## 2. 주제
* 데이콘 거래소에서 수집한 데이터를 이용해 미래의 비트코인 가격 예측
* 1시간 단위로 수집된 비트코인 가격 데이터를 활용하여, 미래의 비트코인 가격(Close) 예측
## 3. 결과
* LSTM 모델 기반 비트코인 가격 예측
* Ranked in 2/20
